How This Works

You will be presented with pitot-static system failure scenarios. For each scenario, you must predict how each of the six primary flight instruments will behave.

The Big Six instruments:

ASI (Airspeed Indicator) -- uses pitot + static
Attitude Indicator -- gyroscopic (never affected)
Altimeter -- uses static only
Turn Coordinator -- gyroscopic (never affected)
Heading Indicator -- gyroscopic (never affected)
VSI (Vertical Speed) -- uses static only

For each instrument, predict: HIGH, LOW, NORMAL, or FROZEN.

After locking in all 6 predictions, click Reveal Answers to see the actual behavior with animated instrument changes and explanations.

Score 5/6 or 6/6 to master a scenario.
