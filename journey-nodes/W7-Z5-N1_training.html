Section 2.0 // Introduction

Why Does This Matter?

Following a heavy maintenance check, a regional jet departs the airspace but Air Traffic Control immediately radios the crew, demanding to know why their radar screen is blank regarding the aircraft's altitude. The technician had inadvertently bumped the transponder control panel from the "ALT" position down to the "ON" position during cockpit cleaning. The transponder was happily pinging back identity codes (Mode A), but was completely failing to transmit altitude data (Mode C). Understanding the distinct operational modes of transponders is critical to deciphering radar failure reports and preventing pilot deviations.

Section 3.0 // Core Principles

What You Need To Know

The Core Radar Physics

A transponder is the avionics foundation of the Air Traffic Control Secondary Surveillance Radar (SSR) system. Unlike primary radar, which stupidly bounces massive microwaves off the metal skin of an aircraft, SSR is an intelligent conversation between two computers:

  • The Interrogation (1030 MHz): The rotating ATC ground radar sweep actively commands: "Who are you?"
  • The Reply (1090 MHz): The aircraft transponder instantly fires a high-powered digital burst back saying: "I am Flight 123 at 14,000 feet."

The Three Operational Modes

  1. 1. Mode A (Identity Only): The most basic legacy mode. The transponder replies exclusively with its 4-digit octal assigned Squawk Code (e.g., 1200 for VFR, 7700 for Emergency). ATC sees a dot on the screen with a code name, but has absolutely no idea how high the aircraft is.
  2. 2. Mode C (Identity + Altitude): The mandatory standard for controlled airspace. The transponder reaches out to an onboard blind altitude encoder or air data computer, grabs the current uncorrected pressure altitude (e.g., Flight Level 240), and transmits it seamlessly alongside the Mode A squawk code.
  3. 3. Mode S (Selective Intelligences): The modern global standard. Instead of blindly blasting replies to every radar sweep, it incorporates a deeply interwoven data link and a unique microchip identifier.

The Power of Mode S and the ICAO Address

Every single Mode S aircraft is hard-coded with a mathematically globally unique 24-bit ICAO address (essentially a permanent MAC address for the airplane).

  • Because of this unique address, ATC can perform Selective Interrogation. The radar can ask "Only aircraft 10101011, what is your status?" and all other aircraft instantly remain silent, massively cleaning up global radio congestion.
  • Mode S transponders can also stream massive amounts of internal flight data (heading, airspeed, roll angle) down to advanced ATC computers.

Section 4.0 // Practical Application

On The Job

Standard Operating Procedure

When heavily installing or troubleshooting a Mode S transponder system, the single most critical configuration step is manually programming the 24-bit ICAO address (usually coded in Hexadecimal via the front panel menus) to perfectly match the aircraft's FAA registration matrix. If you mistype a single character in the Hex code during installation, ATC systems will wildly misidentify the aircraft, safety systems like TCAS will fail to resolve conflicts, and the FAA will flag the airframe for immediate grounding due to data corruption.

Reference Terms

Transponder squawk code

Transponder squawk code

A squawk code is a 4-digit octal number (0000–7777, excluding some) assigned by ATC to identify a specific aircraft on radar. The transponder replies to radar interrogations with the code, allowing controllers to correlate the radar return with the specific flight.

Transponder primary purpose

Tap to expand definition
Transponder primary purpose

The transponder replies to Secondary Surveillance Radar (SSR) interrogations from ATC ground stations. SSR interrogates at 1030 MHz; transponder replies at 1090 MHz with squawk code and altitude. This allows ATC to positively identify and track the aircraft on radar.

Transponder antenna installation requirements

Tap to expand definition
Transponder antenna installation requirements

Transponder antennas operate at 1030/1090 MHz. Installation: (1) verify 50Ω impedance match, (2) use appropriate coax (low-loss type at ~1 GHz, e.g., RG-400 or similar), (3) torque TNC or BNC connectors per spec, (4) verify SWR after installation.

Mode S 24-bit ICAO address

Tap to expand definition
Mode S 24-bit ICAO address

Mode S assigns each aircraft a unique 24-bit ICAO address (set during manufacture/registration). ATC systems use this to selectively interrogate specific aircraft (not all-call interrogation like Mode A/C). Enables data link, reduces RF congestion, and supports ADS-B Out transmission.

Mode C transponder

Tap to expand definition
Mode C transponder

Mode C replies include Mode A squawk code PLUS pressure altitude (Gillham code from encoding altimeter or ADC). Altitude is transmitted in 100-ft increments referenced to 29.92 inHg (standard pressure). ATC can see both aircraft identity and altitude on their display.

Transponder antenna

Tap to expand definition
Transponder antenna

Transponder antennas are low-profile blade or stub antennas tuned to 1030/1090 MHz (L-band). Mounted on the belly (bottom of fuselage) and/or top of fuselage. Low profile to minimize drag. 50Ω impedance.

Mode C — combined ID and altitude

Tap to expand definition
Mode C — combined ID and altitude

Mode C is the standard operating mode for IFR flight, providing both Mode A squawk code (identity) and pressure altitude in a single transponder reply. Most ATC radar requires Mode C in controlled airspace above 10,000 MSL and near Class B/C airports.
