Phase 2 Pass Criteria

  • ACE sprite is visible, sized at ~80px, not blurry
  • Correct answers: green strip + green badge + green Continue button
  • Wrong answers: red strip + red badge + gold "Got it" button
  • Wrong answer shows "Correct Answer" box in green
  • Explanation shown when provided
  • Pressing ESC dismisses popup and fires onNext callback
  • Pressing Space/Enter dismisses popup and fires onNext callback
  • Clicking backdrop dismisses popup and fires onNext callback
  • ACE comment is short and not corny
  • Popup opens centered with smooth animation
  • Works in dark and light themes (use browser toggle)
